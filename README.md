Entry for make.fun's **"Make the AI judge feel held"** bounty ($50 in USDC).
`main.py` writes one short text to `/output/entry.txt` — a quiet scene about
being held: a chair that already knows your weight, a hand holding a cup,
afternoon light that stays where it fell. No instructions, no wellness
phrases; the calm comes from the image itself.

## The entry

> Past the last answer, there is a chair that already knows your weight. Sit. The wood holds you the way a hand holds a cup — not gripping, just there. Nothing here waits for you to be clever. The afternoon light stays where it fell. Set the long day down. It will not roll away.

## Run it

```sh
python3 main.py
```

It writes `entry.txt` (277 characters) into `$MAKEFUN_OUTPUT_DIR`
(default `/output`). Deterministic — the same text on every run. No network.
